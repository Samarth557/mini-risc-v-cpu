# Digital Design: RISC-V Subset CPU

> Draft. The RTL here is the copy of my CPU from the DV submission. The uploaded DD repo zip is the
> club's starter version, so it was used only to tell provided files apart from mine.

A CPU written for the SiliconJackets Fall 2026 Digital Design onboarding. It runs a
subset of RV32I (ADD, ADDI, SUB, SLL, SRL, LW, SW, BEQ, EBREAK) out of a 1024-word instruction SRAM and a
1024-word data SRAM, and its register file can be read from outside the chip once the CPU halts.

## Modules

The files sit in `src/verilog/cpu/`, the same place as in the onboarding repo. Authorship below
comes from comparing my CPU against the club's starter repo.

| File | Role | Source |
| --- | --- | --- |
| `decode.sv` | Field extraction and immediate generation | Mine (not in starter) |
| `execute.sv` | ALU, shifts and branch comparison | Mine (not in starter) |
| `mem_access.sv` | LW/SW requests to data SRAM | Mine (not in starter) |
| `writeback.sv` | Selects ALU result or loaded data for the destination | Mine (not in starter) |
| `cpu_top.sv` | Stage wiring and stall logic | Club stub, completed by me |
| `fetch.sv` | Instruction fetch | Club-provided; I only added comments |
| `reg_file.sv` | 32 x 32 register file, `x0` reads as zero | Club-provided, unchanged |
| `cpu_pkg.sv` | Instruction-type enum | Club-provided, unchanged |

## Folder layout

This folder follows the onboarding repo's layout, so the simulation flow runs from `sim/behav`.

| Path | Contents | Source |
| --- | --- | --- |

| `src/verilog/sram_wrapper.sv` | Read/write wrapper around the 1024 x 32 SRAM macro | Club-provided |

## Running it

Both flows share `sim/behav` and run from this folder with Cadence Xcelium. They were run on Georgia Tech's ECE servers; without Xcelium, its license and the club's setup they can be read but not rerun.

The targets:

```sh
make test TEST=add      # one RTL test: assembles tests/add and runs tb_processor on the CPU
make regress            # every RTL test, PASS/FAIL per test
make dv SEED=1          # verification suite (cpu_tb_top) on the CPU
```

The RTL tests need a RISC-V assembler: put `riscv-none-elf-as` on `PATH` or set `RISCV_AS` to it.

Not included: the encrypted bug-hunt CPUs (`bug_hunt_cpu_*/*.svp`), which belong to the club.
`sim/behav/Include/bug_hunt.include` still lists them, so the bug-hunt run cannot be repeated from
this repo; its results are in [dv/](../dv/README.md).
